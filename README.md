# AI-Powered Chatbot Interface for Spherical Surveillance Robot

This is a full-stack web application designed to interact with a surveillance robot project. It uses a chatbot powered by **Google Gemini AI** to answer user queries based on project documentation.

## Features

- Chatbot UI built with **React.js** and **Framer Motion**
- Backend built using **Node.js** and **Express**
- Reads and processes project PDF documentation
- Uses **pdf-parse** for text extraction and **cosine similarity** for search
- Integrates **Gemini API** for natural language responses
- Smart context-aware prompting for document-based Q&A

---

## Tech Stack

- **Frontend:** React.js, Framer Motion, Axios
- **Backend:** Node.js, Express
- **AI Integration:** Google Gemini API (Embedding + Chat)
- **Utilities:** pdf-parse, cosine similarity
